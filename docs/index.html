Возможности

Игра, которая делает жизнь лучше

Привычный список дел превращается в петлю прогресса: сделал — получил награду — захотел сделать ещё.

Квесты

Ежедневные, еженедельные и разовые задачи. Четыре уровня сложности, автоматические награды и все незакрытые дела дня на главной.

Привычки и серии

Позитивные и негативные привычки, streak, личные рекорды, коэффициент дня и бонусный опыт за длинную серию.

Прокачка героя

Уровни, звания, шкала опыта и четыре характеристики: сила, интеллект, воля и харизма.

65 достижений

За квесты, привычки, серии, уровни, характеристики, опыт, награды и планирование. Открываются сами.

Магазин и инвентарь

Покупайте реальные награды за монеты, храните их в инвентаре и используйте с подтверждением количества.

Статистика и хроника

Сколько квестов выполнено, сколько опыта и монет заработано и что происходило в последнее время.

Отчёт героя

Уровень, статистика, характеристики и достижения сохраняются красивой картинкой PNG — можно поделиться.

Живая эмблема

Щит разгорается к 30 дням серии, затем месяц растёт огонёк, а дальше он плавно меняет цвет каждый месяц.

Данные только у вас

JSON на устройстве, атомарная запись, резервные копии, восстановление после сбоя и экспорт/импорт.

Установка

Выберите свою платформу

Один и тот же код работает на Windows, Android и в браузере. Бесплатно и без регистрации.

Windows

Установщик кладёт приложение в профиль пользователя и создаёт ярлыки. Права администратора не нужны.

Без админа Windows 10/11 x64
IRL_Quests_Setup_1.2.exe

Android

APK для телефона. Скачайте файл на устройство или установите через ADB.

Android 7+ arm64 · armv7 x86_64
irl-quests.apk 
adb install -r irl-quests.apk

Docker

Веб-версия на nginx. Загрузите образ и поднимите контейнер — приложение откроется на порту 8080.

Self-hosted nginx 94 MB
irl-quests-web-1.2.tar 
docker load -i irl-quests-web-1.2.tar
docker compose -f docker-compose.deploy.yml up -d

Приватность по умолчанию. Нет аккаунтов, аналитики и сетевых запросов. Прогресс лежит в JSON на вашем устройстве, а экспорт и импорт позволяют перенести его куда угодно.

Открытый код

Соберите сами за пару команд

Проект целиком на Python и Flet: логика отделена от интерфейса и покрыта тестами. Форкайте, изучайте, предлагайте улучшения.

  • Python 3.12+
  • Flet 1.0.5
  • JSON-хранилище
  • PyInstaller
  • Inno Setup
  • Docker + nginx
  • pytest
Открыть на GitHub Сборка → 
git clone https://github.com/Lstrzz/IRL-Quests.git
cd IRL-Quests

python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install "flet[all]==1.0.5"

flet run src/main.py        # окно
flet run --web src/main.py  # браузер

pip install -e ".[dev]"
pytest
